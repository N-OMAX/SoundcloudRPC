## 🎵 Was ist SoundCloudRPC?
SoundCloudRPC ist ein leichtgewichtiges Desktop-Programm, das in Kombination mit einer Browser-Erweiterung funktioniert. Es erkennt automatisch, welchen Song du gerade auf **SoundCloud** abspielst, und zeigt ihn – genau wie bei Spotify – direkt in deinem Discord-Status an (inklusive Cover-Art, Songtitel, Künstler, aktueller Spielzeit und einem Button zum Mithören).

### ✨ Features
* 🎧 **Echtzeit-Tracking** - Titel, Künstler, Album-Cover und exakter Fortschrittsbalken.
* 🚀 **Discord Rich Presence** - Vollständige Integration in den Discord-Status.
* 💻 **Minimierter Betrieb** - Das Programm läuft komplett unauffällig im Hintergrund (System Tray).
* ⚙️ **Autostart** - Kann so konfiguriert werden, dass es beim Windows-Start automatisch mitläuft.

## 📥 Installation & Setup

Die Einrichtung besteht aus zwei einfachen Schritten: Dem Desktop-Programm und der Browser-Erweiterung.

### Schritt 1: Das Desktop-Programm
1. Gehe zu den [Releases](https://github.com/N-OMAX/SoundcloudRPC/releases/latest) auf GitHub.
2. Lade dir die neueste **`SoundCloudRPC Setup 1.0.0.exe`** herunter.
3. Führe die `.exe` aus und folge den Installationsanweisungen.
4. Das Programm startet sich und minimiert sich bei Bedarf unten rechts in deine Taskleiste.

### Schritt 2: Die Browser-Erweiterung (Pflicht!)
Damit das Programm weiß, was in deinem Browser läuft, benötigst du die dazugehörige Erweiterung (für Chrome / Opera GX / Brave).

1. Lade dir bei den [Releases](https://github.com/N-OMAX/SoundcloudRPC/releases/latest) die **`soundcloudrpc-extension.zip`** herunter.
2. Entpacke die `.zip`-Datei an einen sicheren Ort (z.B. in deine Dokumente).
3. Öffne in deinem Chromium-Browser die Erweiterungen: `chrome://extensions/` (oder `opera://extensions/`).
4. Aktiviere oben rechts den **Entwicklermodus** ("Developer Mode").
5. Klicke auf **"Entpackte Erweiterung laden"** ("Load unpacked") und wähle den Ordner aus, in den du die ZIP-Datei entpackt hast.
6. **Fertig!** Sobald du nun auf SoundCloud Musik hörst, aktualisiert sich dein Discord-Status.

## 🛠️ Fehlerbehebung
* **Auf Discord wird nichts angezeigt?** Stelle sicher, dass unter deinen Discord-Einstellungen -> "Aktivitäts-Privatsphäre" das Teilen von Aktivitäten aktiviert ist.
* **Das Programm erkennt den Track nicht?** Vergewissere dich, dass die SoundCloudRPC-Anwendung (unten in der Taskleiste) läuft und die Browser-Erweiterung im Entwicklermodus aktiv ist.
* **Erweiterung lässt sich nicht installieren?** Achte darauf, dass du wirklich den **Entwicklermodus** in deinem Browser angeschaltet hast.
