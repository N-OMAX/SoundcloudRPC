## 🎵 What is SoundCloudRPC?
SoundCloudRPC is a lightweight desktop application that works alongside a browser extension. It automatically detects what song you are currently playing on **SoundCloud** and displays it—just like Spotify—directly on your Discord status (including cover art, song title, artist, current timestamp, and a listen-along button).

### ✨ Features
* 🎧 **Real-time tracking** - Title, artist, album cover, and exact progress bar.
* 🚀 **Discord Rich Presence** - Full integration into your Discord profile.
* 💻 **Background mode** - The program runs silently in the background (System Tray).
* ⚙️ **Auto-start** - Can be configured to launch automatically when Windows starts.

## 📥 Installation & Setup

The setup consists of two simple steps: the desktop application and the browser extension.

### Step 1: The Desktop Application
1. Go to the [Releases](https://github.com/N-OMAX/SoundcloudRPC/releases/latest) on GitHub.
2. Download the latest **`SoundCloudRPC Setup 1.0.0.exe`**.
3. Run the `.exe` and follow the installation instructions.
4. The program will start and minimize to your system tray.

### Step 2: The Browser Extension (Required!)
For the desktop app to know what is playing in your browser, you need to install the accompanying extension (for Chrome / Opera GX / Brave).

1. Download the **`soundcloudrpc-extension.zip`** from the [Releases](https://github.com/N-OMAX/SoundcloudRPC/releases/latest) page.
2. Extract the `.zip` file to a safe location (e.g., your Documents folder).
3. Open your extensions page in your Chromium-based browser: `chrome://extensions/` (or `opera://extensions/`).
4. Enable **Developer mode** in the top right corner.
5. Click on **"Load unpacked"** and select the folder where you extracted the ZIP file.
6. **Done!** Whenever you listen to music on SoundCloud, your Discord status will update.

## 🛠️ Troubleshooting
* **Nothing is showing up on Discord?** Make sure that "Activity Privacy" is enabled in your Discord settings.
* **The program doesn't detect the track?** Ensure that the SoundCloudRPC application is running (in the taskbar) and the browser extension is active in developer mode.
* **Can't install the extension?** Double-check that you have turned on **Developer mode** in your browser.
